## 目标
`make dev` 一条命令同时启动前后端热更新。

## 方案

### 1. 安装 air（后端热加载）
```bash
go install github.com/air-verse/air@latest
```

### 2. 新增 `.air.toml`（项目根目录）
- 监听 `.go, .yaml, .tpl` 文件变化
- build: `go build -o bin/server ./cmd/server`
- 运行参数：`-conf configs/config.yaml`
- `bin/`、`tmp/` 加入 `.gitignore`

### 3. Makefile 增加 `dev` 目标（一条命令启动前后端）
```makefile
dev: ## 同时启动前后端热更新（air + vite）
	@trap 'kill 0' INT TERM EXIT; \
	air & \
	cd web && npm run dev & \
	wait
```
- `trap 'kill 0'`：Ctrl+C 时同时杀掉两个子进程
- air 后端 :8080 热加载，Vite 前端 :5173 HMR，`/api` 自动代理（`web/vite.config.ts` 已配置）

### 4. README 更新
开发说明改为：`make dev` 一键启动，浏览器访问 http://localhost:5173。

## 最终效果
- 改 Go/配置文件 → air 自动重编译重启后端
- 改 Vue/TS 文件 → Vite 即时 HMR
- Ctrl+C 一次全部停止
