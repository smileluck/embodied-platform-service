# 主题色更换：墨绿×松绿 → 淡雅「清水蓝」

## 新色板（清水蓝）

| 用途 | 旧值（绿） | 新值（蓝） |
|---|---|---|
| 深色墨版/主文字 `--sx-ink` | `#16211D` | `#151E2B` 藏蓝黑 |
| 面板层次 `--sx-ink-soft` | `#233129` | `#212C3E` |
| 全局底 `--sx-bg` | `#F6F7F5` | `#F5F7FA` |
| 主色 `--sx-accent` | `#0F7B5F` 松绿 | `#3F75AB` 柔和钢蓝（白字对比 ≈5:1） |
| hover | `#149373` | `#518CC8` |
| pressed | `#0B5F4A` | `#315E8C` |
| 浅衬底 `--sx-accent-soft` | `#E3F0EB` | `#E4EDF6` |
| 分隔线 `--sx-line` | `#E4E7E4` | `#E3E8EF` |
| 次级文字 `--sx-muted` | `#6B7570` | `#6B7787` |
| 阴影 rgba | `rgba(22,33,29,…)` | `rgba(21,30,43,…)`（与新 ink 同源） |
| 危险色 `--sx-danger` | `#C2453A` | 不变 |
| 登录页点缀色（薄荷绿） | `#7FD4B8` | `#8FC5E8` 亮清水蓝 |
| 登录页面板文字（绿调白） | `#EDF2EF` / `rgba(237,242,239,…)` | `#EDF2F8` / `rgba(237,242,248,…)` |

## 修改文件（5 个）

1. **`web/src/styles/tokens.css`**（单一来源）
   - 替换上表中 10 个色变量 + 阴影 rgba，同步更新注释文案（墨绿黑→藏蓝黑、松绿→清水蓝等）

2. **`web/src/App.vue`**（Naive themeOverrides，与 tokens 同步）
   - `primaryColor/Pressed/Suppl`、`bodyColor`、`textColorBase`、`borderColor` 按上表替换（`cardColor: '#FFFFFF'` 不变）

3. **`web/src/views/login/Login.vue`**（硬编码点缀色）
   - `#7FD4B8` → `#8FC5E8`（6 处：seal 底、mono 标签、脉搏描线、波峰圆点、状态字、live 圆点）
   - `rgba(127,212,184,0.9)` → `rgba(143,197,232,0.9)`（圆点辉光）
   - `#EDF2EF` → `#EDF2F8`；`rgba(237,242,239,…)` → `rgba(237,242,248,…)`（6 处面板文字）
   - 中性白网格线 `rgba(255,255,255,…)` 不动

4. **`web/src/views/login/MapFlow3D.vue`**（canvas 地图唯一颜色源）
   - `const MINT = '127, 212, 184'` → 改名 `SKY = '143, 197, 232'` 并更新注释，替换全部引用（约 12 处 `rgba(${MINT},…)`）

5. **`web/src/views/system/Menus.vue`**（CSS var 绿色 fallback）
   - `#2f5d50` → `#3F75AB`（2 处）、`#eef5f0` → `#E4EDF6`

> 侧边栏/AdminLayout/Dashboard 均引用 token，自动生效，无需改动。`type="success"` 语义绿与 danger 红保留。

## 构建与验证

1. `cd web && npm run build`（air :8080 托管 dist，必须重建）
2. 浏览器打开 `localhost:8080` 截图验证登录页（藏蓝面板 + 清水蓝波形/地图）和后台页（侧边栏 seal、主按钮、选中态），截图落盘后 Read 检查
