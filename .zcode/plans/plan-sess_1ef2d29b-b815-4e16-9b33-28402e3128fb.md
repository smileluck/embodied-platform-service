# 实现计划：登录页记住密码+验证码 & 侧边栏折叠

## 任务 1a：后端新增图形验证码（base64captcha）

**1. 引入依赖**
- `go get github.com/mojocn/base64captcha`（仅用其 Driver 画图能力，答案存储自实现，对齐项目内 RBAC 内存缓存先例，单实例无需 Redis）

**2. 新建 `internal/biz/captcha/usecase.go`**
- `Usecase`：`sync.Mutex` + `map[id]{answer, expireAt}`（TTL 3 分钟，Generate 时顺手清理过期项）
- `Generate() (id, b64Image string, err error)`：`base64captcha.NewDriverString(...)` 生成 4 位字母数字扭曲图 → `EncodeB64string()` → id 用 `crypto/rand` 16 字节 hex
- `Verify(id, answer string) bool`：一次性取出即删，`strings.EqualFold` 忽略大小写比对

**3. `internal/biz/auth`（entity.go + usecase.go）**
- 新增错误 `ErrCaptcha`、小接口 `CaptchaVerifier { Verify(id, answer string) bool }`（与 UserReader 同级，遵循依赖倒置惯例）
- `Usecase` 注入 `captcha CaptchaVerifier`；`Login` 签名扩展为 `(ctx, username, password, captchaID, captchaCode string)`，开头先校验验证码

**4. `internal/service/auth/service.go`**
- `LoginRequest` 增加 `CaptchaID`/`CaptchaCode`（均 `binding:"required"`）
- `Service` 注入 captcha usecase，新增 `GenerateCaptcha()` 返回 `CaptchaVO{captcha_id, captcha_image}`

**5. wire 依赖注入（`cmd/server/wire.go` + `wire_gen.go`）**
- `bizSet` 加 `bizcaptcha.NewUsecase`；`dataRepoSet` 加 `wire.Bind(new(auth.CaptchaVerifier), new(*bizcaptcha.Usecase))`
- 优先 `go run github.com/google/wire/cmd/wire ./cmd/server` 重新生成，不可用则手改 `wire_gen.go`（结构简单）

**6. `internal/server/http.go`**
- 公开组新增 `GET /api/v1/auth/captcha`（无需鉴权）
- login handler：`errors.Is(err, bizauth.ErrCaptcha)` 时返回 `response.BadRequest`（400），其余保持 401 现状

## 任务 1b：前端登录页（Login.vue + api + store）

**7. API 层**：`types.ts` 加 `CaptchaInfo`；`index.ts` 加 `getCaptcha()`，`login` 参数扩展 `captcha_id`/`captcha_code`；`stores/user.ts` 的 `login` action 透传

**8. `web/src/views/login/Login.vue`**
- 验证码行：`n-input`（flex:1，size large）+ 验证码图片（高 40px、圆角 `var(--sx-radius)`、边框 `var(--sx-line)`，`src` 拼 `data:image/png;base64,` 前缀，点击刷新，加载中有占位）
- 密码框与登录按钮之间加 `n-checkbox`「记住密码」
- `onMounted`：回填记住的账号（`atob` 解析 localStorage `remember_account`）+ 拉取验证码
- 登录成功：勾选则存 `btoa(JSON{username,password})`，未勾选则移除该 key
- 登录失败：自动刷新验证码、清空验证码输入；`/captcha/i` 匹配后端 msg 时提示中文「验证码错误，请重新输入」
- 顺手修复 `validate()` 失败时的 unhandled rejection（校验失败直接 return）

## 任务 2：AdminLayout 侧边栏折叠（顶部汉堡按钮 + 持久化）

**9. `web/src/layout/AdminLayout.vue`**

- 移除 `show-trigger` / `@collapse` / `@expand`，保留 `:collapsed` 联动（logo/菜单/脚注已适配）

- `.header-left` 调整为 row 布局：汉堡按钮 + 原 eyebrow/标题 column 组合
