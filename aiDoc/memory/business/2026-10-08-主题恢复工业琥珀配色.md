# 主题恢复工业琥珀配色（登录页/全站）

## 需求描述

用户反馈登录页配色从橙红（工业琥珀）变成了蓝色，要求恢复之前的配色，同时避免暗色（黑夜）模式下的显示问题。

## 状态

已完成

## 涉及范围

### 前端

- 主题唯一来源 `web/src/styles/variables.css` 整体恢复旧「石墨深壳 + 工业琥珀」色板（`#D97706` 主色 / `#FFB224` 高亮 / `#17191E` 石墨壳 / 暖白工作面），并补回此前丢失的 `--sx-ok` / `--sx-ok-bright` / `--sx-warn` 状态灯语 token
- 暗色模式：保留亮/暗双套结构，`html.dark` 的 `--sx-accent-soft` 改琥珀色 rgba、`--sx-ok` 提亮为磷光绿
- 登录页品牌印章文字色由随主题反转的 `--sx-ink` 改为恒深 `--sx-panel`（暗色下避免浅字压浅底）
- 各页面硬编码清水蓝色值（图表曲线、rgba 衬底、readVar fallback）全部换成琥珀色或 `rgba(var(--sx-accent-rgb), …)`

## 约束与备注

- 主题色只改 `variables.css`，naive-ui overrides / 图表 / 首屏动画均从该文件取值
- 恒定深底元素（品牌面板、深壳侧栏）上的文字禁止用随主题反转的 `--sx-ink`，用 `--sx-panel` / `--sx-shell-text`
