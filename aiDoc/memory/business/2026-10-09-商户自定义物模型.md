# 商户自定义物模型（物模型页升级为可管理）

## 需求描述

商户可自定义物模型：平台开放面放物模型写端点后，本服务物模型页从只读浏览升级为完整管理（节点 CRUD + 版本草稿/发布/回滚）。约束：**通用节点不允许修改**（写仅本商户，通用/他商户 404）；**看不到其他商户的节点**（读=通用+本商户，既有收敛已保证）。

## 状态

已完成

## 涉及范围

### 后端

- 平台：开放面 `/open-api/v1/thing-models*` 写端点（scope thing-model:write）——平台仓库变更
- 本服务：platformsdk 物模型写方法镜像；biz/devmodel 的 Gateway 扩展 + data 适配器；/api/v1/thing-models* 路由扩展（节点详情/写、版本写、resolve/inheritance-status）；thingModel:* 权限种子扩展

### 前端

- `web/src/views/device/ThingModels.vue` 升级为可管理（2026-10-09 完成）：本商户节点新建/编辑/删除、版本管理（草稿/发布/回滚）；通用节点只读展示
- 草稿无开放面枚举端点：前端 localStorage 会话跟踪（见 `aiDoc/notes/implemented/feature/2026-10-09-thingmodel-draft-local-tracking.md`）
- API 函数与 locale 增补（`TMSchemaViewer.vue`/`TMSchemaEditor.vue` 页面私有组件）

## 约束与备注

- 通用节点（merchant_id=0）只读，平台管理面维护
- 父链校验（商户节点可挂通用父节点下）由平台 biz 保证，本服务透传 409/404 msg
- 商户须在平台配 `thing-model:write` scope（漏配 403）
