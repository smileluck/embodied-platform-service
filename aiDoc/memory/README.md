# 记忆层

`aiDoc/memory/` 是 AI 的记忆层，用于跨会话保留用户偏好、业务需求与经验教训上下文。

## 目录说明

| 目录 | 内容 |
|---|---|
| `long-term/` | 跨任务、跨会话长期稳定的用户偏好、协作方式 |
| `business/` | 每次用户提出的业务需求记录 |
| `lessons/` | 踩坑与反复模式的经验 staging 区；达到晋升条件后写进约束正文 |
| `project-memory.md` | 全部记忆的索引 |

## 使用规则

- 用户提出业务需求时，AI 必须新增或更新一条 `business/` 记忆，并更新 `project-memory.md` 索引
- 踩坑、review 反复发现同类问题、或发现可复用模式时，必须在同一变更内记一条 `lessons/` 记录；同类再犯时就地累加出现次数，第二次出现时按 `lessons/README.md` 晋升纪律写进约束正文
- 某条经验沉淀为稳定模式时，提炼到 `long-term/`
- 临时草稿不入库
- 过时记忆及时清理，并同步清理索引

## 与其他层的边界

- 记忆层只存"上下文与偏好"，不存规则正文；稳定规则应进入 `/AGENTS.md` 或对应 aiDoc 子文档
- 决策的理由不存这里，存 [../notes/](../notes/)
